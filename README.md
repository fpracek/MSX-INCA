# THE INCA WALL

MSX1 arcade game (SCREEN 1) by F. Pracek, in three versions:

| folder | what |
|---|---|
| [`ASM/`](ASM) | the original: Z80 assembly, 32 KB cartridge ROM (sjasmplus) |
| [`SAMPRBAS/BASIC/`](SAMPRBAS/BASIC) | the same game rewritten in [SamPr Basic](https://github.com/fpracek/MSX-SAMPRBASIC), compiled to an MSX-DOS `.COM` |
| [`SAMPRBAS/ASM/`](SAMPRBAS/ASM) | a compact version written entirely in assembly, in SamPr Basic's assembler mode (`OPTION ASM`), also an MSX-DOS `.COM` |

The two SamPr Basic versions show the two ways of using that environment on the same game: BASIC compiled to machine code, and pure assembly inside the
same editor and compiler.
